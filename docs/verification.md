# 验证记录

验证日期：2026-11-11。环境：Windows、Node.js 24.16.0、DSH 0.2.2-rc.1、Chrome，通过 Playwright 1.58.2 操作浏览器。

## 构建与状态逻辑

以下命令通过：

```powershell
npm run check
npm test
npm run build
npm pack --pack-destination ..
```

13 项行为测试覆盖并行工具关联、跨轮工具 ID 复用、真实 DSH 结束原因、静默与等待优先级、流式心跳、授权记录、错误与凭据处理、历史上限、未知事件、会话错误、重连、流式结算、订阅释放和会话隔离。

## 真实 DSH 集成

将构建的本地 `.tgz` 通过 DSH Plugin Manager 安装到隔离的 `web` profile，启动 DSH 并打开原生右侧栏。使用仅存在于验证目录的本地测试适配器与延时工具，不使用真实账号、API Key 或外部模型服务。测试适配器通过正式的 LLM 和工具注册接口触发事件，插件读取正式会话事件桥接。

浏览器断言通过：

- 插件出现在原生右侧栏工具列表中，正常渲染。
- 实际会话显示等待模型、等待工具结果、接收输出、本轮已完成。
- 工具完成后成功数为 1，活动列表包含工具和本轮任务，耗时正常。
- 页面刷新后，从 DSH 历史恢复完成状态。
- 静默阈值设为 1 分钟，刷新后仍保留。
- 测试模型返回错误时显示错误状态及对应摘要。
- 浏览器没有未处理的页面异常。

源码目录附有 `docs/dsh-complete.png`，展示这次真实 DSH 集成测试的完成状态。测试模型与测试工具不包含在安装包中。

## 独立预览

使用同一个状态卡组件的模拟预览，验证工具执行、等待用户、静默、断线、完成、错误六种场景。320px 宽度没有横向溢出；人工查看普通宽度、窄屏和模拟深色背景截图。
